# 로봇 축구 자동 점수 시스템

```
[왼쪽 골대 웹캠] → 노트북 A: 감지기(left) + 점수 서버 ─┐
[오른쪽 골대 웹캠] → 노트북 B: 감지기(right) ───────────┼→ 스탠바이미 웹 브라우저: http://<노트북A IP>:8000/
                                                       └→ 심판 폰/노트북:      http://<노트북A IP>:8000/admin
```

- **left / right 의미**: 점수판 화면 기준 왼쪽 팀 / 오른쪽 팀이 **지키는** 골대.
  왼쪽 골대(`--goal left`)에 공이 들어가면 **오른쪽 팀**이 1점을 얻음.
- 골대 뒤가 막혀 있어서 공이 안에 남는 걸 전제로 함: 공이 감지되면 골 1번, **공을 빼야** 다음 골을 다시 감지함.

## 1. 설치 (노트북 2대 모두)

1. 이 폴더 전체를 두 노트북에 복사
2. Python 3.10 이상 설치 (설치할 때 "Add python.exe to PATH" 체크)
3. `1_install.bat` 더블클릭

## 2. 네트워크

- 노트북 2대 + 스탠바이미 + 심판 폰이 **같은 공유기**에 연결돼야 함 (인터넷은 필요 없음)
- REV 컨트롤 허브 Wi-Fi와 겹치지 않게 공유기 채널을 다르게 잡기. 가능하면 노트북은 유선 랜으로 연결
- 노트북 A의 IP 확인: 서버를 켜면 창에 주소가 출력됨 (또는 `ipconfig`)

## 3. 실행 순서

1. **노트북 A**: `2_server.bat` 실행
   - 처음 실행할 때 윈도우 방화벽 창이 뜨면 **개인/공용 둘 다 허용**
   - 방화벽 창이 안 뜨고 다른 기기에서 접속이 안 되면, 관리자 PowerShell에서:
     `netsh advfirewall firewall add rule name="robot-soccer" dir=in action=allow protocol=TCP localport=8000`
2. **노트북 A**: `3_detector_left.bat` → 서버 IP는 그냥 Enter (같은 노트북)
3. **노트북 B**: `3_detector_right.bat` → 노트북 A의 IP 입력
4. **스탠바이미**: 웹 브라우저에서 `http://<노트북A IP>:8000/` → 화면 한 번 누르면 전체화면
5. **심판**: 폰/노트북에서 `http://<노트북A IP>:8000/admin` → 카메라 두 개가 **초록불(온라인)**인지 확인

카메라 번호를 모르면: `cd detector` 후 `python goal_detector.py --list-cameras`
(노트북 내장 카메라가 0번이면 USB 웹캠은 보통 1번)

## 4. 카메라 맞추기 (골대마다 한 번, 경기장 조명에서)

감지기 창이 뜨면:

1. **판정 영역 지정**: 카메라 화면에서 골라인 안쪽(공이 들어오면 골인 영역)의 꼭짓점을 마우스로 차례대로 클릭 (3개 이상). 오른쪽 클릭은 되돌리기, `r`은 초기화
2. **색 맞추기**: `p` 눌러 색 찍기 모드 → 화면 속 보라색 공을 클릭 → 다시 `p`로 모드 끄기
3. `m`으로 마스크 창을 켜서 확인: 공만 **하얗게** 보이고 나머지는 검정이어야 함
   - 다른 것도 하얗게 잡히면 `settings` 창에서 `S low`를 올리기
   - 공이 잘 안 잡히면 `V low`를 내리거나 `H low/high` 범위를 넓히기
4. 공을 넣었다 뺐다 하면서 `ball=YES`가 뜨는지, `area`가 `min area`보다 충분히 큰지 확인
   - 로봇 일부가 잘못 잡히면 `min area`를 올리기
5. **`s`로 저장** (`detector/config_left.json` 또는 `config_right.json`에 저장되고 다음 실행 때 자동으로 불러옴)
6. `g`를 누르면 테스트 골이 서버로 감 (심판 페이지 기록에 뜨는지 확인)

> 테스트할 때는 심판 페이지 설정의 "경기 진행 중일 때만 자동 득점 인정"을 끄거나, 경기를 시작한 상태에서 하기.
> 끝나면 다시 켜고 "새 경기"로 초기화.

## 5. 경기 운영 (심판 페이지)

- **시작 / 일시정지 / 새 경기**: 버튼, 또는 키보드 Space
- 자동 판정이 틀리면 팀별 **+1 / −1** 버튼으로 바로 수정 (키보드 1 = 왼쪽 +1, 2 = 오른쪽 +1)
- 경기 시간: 설정에서 1:00 / 1:30 / 2:00 / 3:00 또는 직접 입력 → 저장
- 시간이 끝나면 자동으로 종료되고 점수판에 승리 팀이 표시됨
- 같은 골대에서 3초 안에 다시 들어온 감지는 중복으로 보고 무시
- 서버가 꺼졌다 켜져도 점수는 `server/state.json`에 남아 있음 (진행 중이었으면 일시정지 상태로 복구)

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 감지기 화면에 `server OFFLINE` | 서버 켜져 있는지, IP 맞는지, 같은 공유기인지, 방화벽 |
| `NO CAMERA` | USB 다시 꽂기, `--list-cameras`로 번호 확인 |
| 공이 안 들어갔는데 골 | 판정 영역 다시 지정, `S low` / `min area` 올리기 |
| 공이 들어갔는데 무반응 | 마스크 창 확인, `p`로 색 다시 찍기, 화면 상단이 `ARMED`인지 (공을 빼야 재무장) |
| 조명 때문에 색이 계속 바뀜 | 감지기 실행 시 `--exposure -6` 같은 수동 노출값 추가 (웹캠마다 다름, -4 ~ -8 시도) |
| 스탠바이미에서 화면 안 뜸 | 같은 Wi-Fi인지 확인, 주소 앞에 `http://` 붙였는지 |
